# Assets Directory

This directory contains visual assets for the extension documentation.

## GIF Creation Guide

### Recommended Recording Settings:
- **Resolution**: 1280x720 or 1440x900
- **Frame Rate**: 15-20 FPS (keeps file size reasonable)
- **Duration**: 5-10 seconds per demo
- **Format**: GIF (under 2MB each for marketplace compatibility)

### Files to Create:

1. **demo-formatting.gif**: Shows basic JSON formatting with Ctrl+Alt+F
2. **demo-list-formatting.gif**: Shows list compact formatting with Ctrl+Alt+L  
3. **demo-sorting.gif**: Shows interactive array sorting with Ctrl+Alt+S

### Recording Steps:

#### For demo-formatting.gif:
1. Open `demo-basic-formatting.json` (minified JSON)
2. Press `Ctrl+Alt+F` (or `Ctrl+Cmd+Alt+F` on Mac)
3. Show the beautifully formatted result
4. Keep recording under 8 seconds

#### For demo-list-formatting.gif:
1. Open `demo-list-formatting.json` (minified array)
2. Press `Ctrl+Alt+L` (or `Ctrl+Cmd+Alt+L` on Mac)
3. Show each array item on single line
4. Keep recording under 8 seconds

#### For demo-sorting.gif:
1. Open `demo-sorting.json` (unsorted array)
2. Press `Ctrl+Alt+S` (or `Ctrl+Cmd+Alt+S` on Mac)
3. Show property picker dialog appearing
4. Select a property (like "name")
5. Show sorted and formatted result
6. Keep recording under 10 seconds

### Tools for macOS:
- **LICEcap** (Free): https://www.cockos.com/licecap/
- **Kap** (Free): https://getkap.co/
- **CleanShot X** (Paid): Available on Mac App Store

### VS Code Marketplace Requirements:
- File size under 2MB per GIF
- Dimensions reasonable (not too large)
- Clear, readable text in recordings
- Smooth playback
